# E-Commerce Growth Analytics

**Portfolio project analyzing growth leakage across an e-commerce business using the theLook eCommerce dataset.**

---

## Purpose

Identify where an e-commerce business is losing growth — across acquisition, funnel conversion, retention, product performance, and fulfillment — and surface actionable recommendations backed by data.

Core business question: *"Where is this e-commerce business leaking growth: acquisition, conversion, retention, product mix, or fulfillment?"*

---

## Tools

| Tool | Role |
|------|------|
| BigQuery | Data access and SQL analysis |
| Python (pandas, matplotlib, scipy) | Data wrangling and visualization |
| Jupyter Notebooks | Exploratory analysis |
| Tableau | Executive dashboards |
| GitHub | Version control |

## Dataset

**theLook eCommerce** — a synthetic but realistic e-commerce dataset hosted on Google BigQuery (`bigquery-public-data.thelook_ecommerce`). Includes orders, order items, users, products, inventory, events, and distribution center data.
